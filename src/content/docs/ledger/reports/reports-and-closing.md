**Reports** has the standard reports. When a period is done, use **Close the books** (under **Settings**) so it
can't be changed by accident.

## Add to a board package

If your organization uses OpenBoardApp, **Add to a board package** next to **Board package (PDF)** sends the
report as a PDF to an upcoming meeting. It goes into that meeting's documents and its board packet.
