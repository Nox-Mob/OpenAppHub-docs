OpenLedgerApp is **pre-release software** (0.1.1).

## Not supported

| Feature | Notes |
|---|---|
| **Accrual accounting** | Reports are cash basis |
| **Invoices, bills, money owed to and by you** (A/R and A/P) | Planned |
| **Automatic bank feeds** | Import bank files instead |
| **Receipt attachments** | Planned |
| **Multiple currencies** | One currency per organization |
| **Payroll** | Not planned |
| **Sync between the desktop app and the web app** | Planned later |

## Desktop app gaps

History, exports, backups, bank import, PDF statement reading, and members and invitations are web-only for now. See [The desktop app](/ledger/start/desktop-app/).

## Still being checked

- a screen-reader pass by a person
- a self-hosting installer, upgrade tests and restoring backups across versions
- testing with people who aren't accountants

See the [roadmap](https://github.com/Nox-Mob/OpenLedgerApp/blob/main/roadmap.md).
