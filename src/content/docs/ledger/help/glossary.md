title: "Glossary"
description: "Bookkeeping words OpenLedgerApp uses, in plain English."
sidebar:
  order: 5
---

| Term | Meaning |
|---|---|
| **Account** | A bucket money is counted in: a bank account, an income type, an expense type and so on |
| **Assets** | What you own (Money You Have) |
| **Liabilities** | What you owe (Money You Owe) |
| **Equity / Net assets** | What's left after debts |
| **Revenue / Income** | Money coming in |
| **Expenses** | Money going out |
| **Double-entry** | Every transaction touches at least two accounts and balances |
| **Debit / Credit** | The two sides of an entry (Increase / Decrease in plain wording) |
| **Post** | Record a transaction in the books |
| **Void** | Cancel a posted transaction while keeping it in the history |
| **Opening balance** | What an account held on your start date |
| **Template** | A saved transaction you reuse; can repeat |
| **Ready to review** | Recurring transactions due, waiting for you to post or skip |
| **Bank row** | A line from an imported bank file; evidence until posted |
| **Statement check / reconciliation** | Confirming your books match a bank or card statement |
| **Cash basis** | Income and expenses counted when money moves |
| **Fund** | Money tracked separately, often for a donor's purpose |
| **Restricted / unrestricted** | Whether a donor limited how money can be used |
| **Release from restriction** | Moving money out of a restricted fund when its purpose is met |
| **Pledge** | A promised gift not yet fully paid |
| **Write off** | Recording that part of a pledge won't arrive |
| **Project** | A piece of work with its own budget |
| **Category / tag** | Extra ways to group transactions |
| **Budget vs actual** | Planned amounts compared with what happened |
| **Month close / year-end close** | Locking a period so it can't be changed by accident |
| **Books lock** | The date on or before which nothing can be posted or voided |
| **Reopen** | Unlocking a closed period, with a written reason |
| **Trial balance** | Every account's total (Totals Check) |
| **General ledger** | Every transaction in every account (Every Transaction) |
| **Board package** | One PDF of the key reports for your board |
| **Full backup** | A signed file with everything, restorable into a new organization |
| **History** | The permanent record of every change |
