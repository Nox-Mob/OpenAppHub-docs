A **template** is a saved transaction you use again: a name, accounts and amount.

## Create a template

**Templates → New template.** Enter a **name**, the **accounts** and the **amount**, and how often it **repeats**:

- **Doesn't repeat** (use it whenever you like)
- weekly, monthly, every 3 months or yearly

## When a recurring one is due

Nothing posts by itself. Choose what happens when a template is due:

- it waits in a **Ready to review** list, where you **post** or **skip** it, or
- you get a **reminder** notice.

**Next due** shows when each template comes up next.

Posting the same due date twice still creates only one transaction, so a double click can't double-record your rent.

## Changing amounts

If this month's amount is different (a utility bill, say), change it before posting. The template stays the same for next time.
