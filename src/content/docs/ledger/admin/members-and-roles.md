**Settings → Users & roles** (web app only; the desktop app has one user).

## Roles

| Can… | Admin | Treasurer | Member | View only |
|---|:-:|:-:|:-:|:-:|
| See the books, reports and exports | ✓ | ✓ | ✓ | ✓ |
| Post and void transactions, import, run statement checks | ✓ | ✓ | ✓ | |
| Reopen a finished statement check | ✓ | ✓ | | |
| Lock the books, close months and years, reopen | ✓ | ✓ | | |
| Change settings and accounts | ✓ | | | |
| Manage people and roles | ✓ | | | |

The organization also has one **Owner**, who is an admin and the only one who can transfer ownership or delete the organization.

The database enforces the same rules as the screens.

## Invite someone

**Invite someone**: choose a role and copy the link. Links work once and expire after **7 days**. Admins can revoke unused links.

## Change a role or remove someone

Change a person's role or remove them. Removed people lose access on their next action.

- The organization's **last admin** can't be removed or demoted: **Make someone else an admin first.**
- Anyone except the owner can **leave** an organization.

## Transfer ownership

**Transfer ownership** → **Choose an admin**. Only the owner can do this, and only to an existing admin.

## Delete the organization

The owner can delete the organization after typing its name. This can't be undone. Download a [full backup](/ledger/admin/backups-and-exports/) first.
