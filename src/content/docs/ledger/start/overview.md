| Menu                                              | What's there                                         |
| ------------------------------------------------- | ---------------------------------------------------- |
| **Dashboard**                                     | Cash, income, expenses and what needs attention.     |
| **Transactions**                                  | Every transaction. Add one with **New Transaction**. |
| **Templates**                                     | Transactions you enter often.                        |
| **Accounts**                                      | Your chart of accounts.                              |
| **Import Bank File**                              | Bring in a bank statement to review.                 |
| **Reconcile**                                     | Match your books to your bank statement.             |
| **Projects**, **Budgets**, **Funds**, **Pledges** | Track money by purpose.                              |
| **Reports**                                       | Standard reports.                                    |
| **Settings**                                      | Users, closing the books, exports and more.          |
