Everyone in the organization has one **app role**. It decides what they can do in the app.

| Can… | Owner | Administrator | Chair | Secretary | Treasurer | Board member | Observer |
|---|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| Read meetings, minutes, documents and records | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| Edit records (meetings, agendas, attendance, motions, documents) | ✓ | ✓ | ✓ | ✓ | | | |
| Approve minutes | ✓ | ✓ | ✓ | ✓ | | | |
| Read the audit log | ✓ | ✓ | ✓ | ✓ | | | |
| Manage the organization (settings, letterhead) | ✓ | ✓ | | | | | |
| Invite people and change roles | ✓ | ✓ | | | | | |
| Export data | ✓ | ✓ | | | | | |
| Transfer ownership | ✓ | | | | | | |

**Voting** in live votes doesn't depend on the app role. It depends on being marked present at the meeting with a linked account. See [Live voting](/board/voting/live-voting/).

## App roles versus board titles

An **app role** is about access. A **board title** (for example "Membership VP") records who holds an office and for how long. Giving someone a title doesn't change what they can do in the app. See [Board roles and terms](/board/people/board-roles-and-terms/).

A typical setup:

- the board chair: **Chair**
- the secretary who takes minutes: **Secretary**
- the treasurer: **Treasurer**
- other directors: **Board member**
- staff or guests who should only read: **Observer**
- whoever manages the app: **Administrator**

## Changing someone's role

**Members**, then change the person's role. Only owners and administrators can do this. There's always exactly one Owner; use [Transfer ownership](/board/start/settings/) to change it.
