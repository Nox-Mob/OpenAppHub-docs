title: "Known limits"
description: "What OpenBoardApp 0.1 doesn't do yet."
sidebar:
  order: 3
---

| Not available | Notes |
|---|---|
| **Email**: invitations and meeting reminders | Copy invitation links and send them yourself. Reminders are planned. |
| **Restorable backups** | Exports are readable copies, not backups. A tested restore routine is planned. |
| **Offline use or a desktop app** | OpenBoardApp needs an internet connection. |
| **Secret ballots** | Votes are recorded openly, as totals or by person. |
| **Voting between meetings** | Live votes only happen during an in-progress meeting. |
| **E-signatures** | Not supported. |
| **Calendar and video-call integrations** | Not supported. |
| **AI transcription** | Not supported. |
| **Accounting and dues** | Use OpenLedgerApp and OpenCharterApp. |

Some multi-step actions (for example creating a meeting and then adding its agenda) are saved as separate steps. If one step fails, you may need to finish the rest by hand; everything that was saved is in the audit log.

See the [roadmap](https://github.com/Nox-Mob/OpenBoardApp/blob/main/roadmap.md).
