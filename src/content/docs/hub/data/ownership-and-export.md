Your organization's information belongs to your organization, not to us. This page explains what that means and how to take a full copy of it at any time.

## Our promises

- **You can export everything, any time.** The owner and admins can download all of their organization's information from each app.
- **Nothing is deleted when a plan or trial ends.** The apps become read-only instead. You can still see and export everything until you choose a plan.
- **Each organization's information is kept apart.** The database itself checks who can see what, on every request. One organization can never see another's information.
- **Important changes are recorded.** The [audit log](/hub/accounts/audit-log/) shows who changed what.
- **Deleting is your choice.** Only the owner can delete an organization. They type its name to confirm, and they must have signed in within the last 15 minutes. Deleting removes its information in every app, and it can't be undone.

## Exporting from each app

| App            | Where                                              | What you get                                                                                                                  |
| -------------- | -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| OpenCharterApp | **Settings** → **General** → **Export everything** | A zip file with one spreadsheet (CSV) for each kind of record and one JSON file. It covers the organization and its chapters. |
| OpenBoardApp   | **Settings & export**                              | The full board record as one JSON file, and each kind of record as a spreadsheet (CSV).                                       |
| OpenLedgerApp  | **Settings** → **Exports**                         | Your transactions as a spreadsheet, and a full backup file you can restore later.                                             |

**What do these file types mean?**

- A **CSV** file opens in any spreadsheet program, like Excel or Google Sheets.
- A **JSON** file holds everything in a standard format that other software can read. It's useful if you ever move to a different system.

**Tip:** export once in a while and keep a copy somewhere safe, like your organization's shared drive. It's good practice for any important records.

## When an app is read-only

When a trial or plan has ended, each app shows a banner saying it's read-only. The buttons and forms that make changes are turned off. Everything you could see before is still there, and the exports above still work.

To turn everything back on, choose a plan on the **Billing** page in OpenAppHub.
