OpenCharterApp 0.1.0 is the first release an association can run on. These features aren't in it yet:

| Not yet available | What to do meanwhile |
|---|---|
| **Automatic email**: invitations, confirmations, receipts and renewal reminders. This is the first update after 0.1.0. | Copy invitation links and send them yourself; print receipts to PDF; members see renewal reminders on their Overview |
| **Postpaid dues and invoices** | Record payments by hand when they arrive |
| **Local chapter dues in the home-chapter model** | Use the separate-memberships model if chapters must collect their own dues |
| **PayPal** | Use Stripe |
| **Custom domains and per-organization web addresses** | Link to your join page from your own website |
| **Approval chains** (beyond approving new members), **board reports**, **document library**, **elections**, **awards**, **automations** | Planned in later releases |
| **CPA-reviewed receipt tax wording** | Check receipts with your accountant |
| **Self-hosting package** | Self-hosting works from the source code; see [Self-hosting](/charter/help/self-hosting/) |

See the [roadmap](https://github.com/Nox-Mob/OpenCharterApp/blob/main/roadmap.md) for progress.
