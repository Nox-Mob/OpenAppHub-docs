**Settings → Audit log** records every important change in your organization.

## Reading it

Entries are grouped by day, newest first. Each reads plainly, for example:

> 8:53:23 PM, Nora National modified Board settings · President

Below each entry, a small table shows every changed field's **Previous** and **Current** value (for example Title: President → Chair).

**One save is one entry.** Applying Membership setup creates one entry, "applied Membership setup", with **Show *N* more changes in this save**. Saving a setup draft doesn't create an entry.

Exports and imports are logged too.

## Filtering

Filter by **person** and by **area**. **Show older changes** loads more.

## Who sees what

Each organization sees **only its own** log. A national's log doesn't show its chapters' changes, and a chapter's log doesn't show the national's.

## It can't be changed

Nobody can edit or delete log entries, including administrators. The app has no option to do so.
