OpenCharterApp is configured, not programmed. Under **Settings**:

| Settings page | What you set |
|---|---|
| **General** | The organization's details. |
| **Setup** | Guided setup: how membership works, prices and the board. |
| **Membership levels** | Levels, terms and prices. |
| **Member fields** | Extra fields on member records. |
| **Chapter fields** | Extra fields on chapters. |
| **Board settings** | Board seats and terms. |
| **Roles** | Roles and permissions, including custom roles. |
| **Payments** | Your organization's own Stripe account for dues. |
| **Audit log** | Every change, who made it and when. |

A national can lock settings so its chapters can't change them, or let chapters override them.
